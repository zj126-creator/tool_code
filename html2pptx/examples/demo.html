HTML 转 PPTX 演示

这是一个从第一性原理出发开发的 HTML→PPTX 转换器。它能将 HTML 内容一字不差地转换为可编辑的 PowerPoint 文件。

核心特性

  • 文本内容完整保留，加粗、斜体、下划线等格式不丢失
  • 字体大小、颜色等样式尽可能保留
  • 图片自动嵌入（支持本地/HTTP/data URI）
  • 表格结构完整保留
    • 表头特殊样式
    • 交替行颜色
  • 列表层级正确映射

表格示例

功能 支持 说明
文本 ✓ 所有文本内容
图片 ✓ PNG/JPEG/GIF/WebP
表格 ✓ 完整表格结构
